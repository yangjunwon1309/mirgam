미르감 사용 안내

고객과 주문을 기록하고, 필요한 내역을 확인하거나 CSV로 저장하는 프로그램입니다. 아래 순서대로 이용하세요.

1

고객 준비

‘고객 확인 및 수정’에서 고객을 직접 등록하거나, ‘상품·고객 파일 관리’에서 고객 XLSX 또는 CSV를 불러옵니다.

2

주문 입력

고객을 선택하고 각 고객의 상품, 수량, 주문일을 입력합니다. 여러 주문에 같은 내용을 적용할 수도 있습니다. 저장을 누르면 CSV를 저장할 위치와 이름을 선택합니다.

3

주문 확인

‘주문 내역 보기’에서 날짜를 선택하거나 고객 이름으로 검색합니다. 현재 조건에 맞는 주문을 CSV로 내려받을 수 있습니다.

고객 파일을 불러올 때

XLSX 또는 CSV 파일을 사용할 수 있습니다. 기본 설정은 첫 번째 줄을 제목으로 보고, CSV는 UTF-8과 쉼표를 사용합니다. 파일의 제목이 다르거나 열 순서가 달라도 미리보기에서 이름, 전화번호, 주소에 해당하는 열을 직접 고르면 됩니다.

미리보기에서 추가될 고객을 확인한 뒤 반영하세요. 기존 고객은 그대로 남습니다. 이름·전화번호·주소가 모두 같은 고객은 중복으로 보고 건너뜁니다. 주문 내역도 유지됩니다.

name,ph,address

저장 위치와 서버

고객·상품·주문은 중앙 서버의 SQLite DB에 저장됩니다. 주문 CSV는 저장 버튼을 누른 뒤 선택한 폴더에 별도로 저장됩니다. 기존 주문을 CSV로 내려받을 때는 날짜와 이름 필터가 적용됩니다.

사이트를 사용할 때는 중앙 서버와 클라이언트 프로그램이 모두 실행 중이어야 합니다. 서버에 연결되지 않으면 잠시 기다렸다가 실행 상태를 확인해 주세요.
