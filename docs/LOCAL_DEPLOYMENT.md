미르감 로컬 데스크톱 실행 안내
================================

1. `Mirgam.exe`를 더블클릭합니다.
2. 기본 웹 브라우저가 자동으로 열리면 미르감을 사용합니다.
3. 사용 중에는 함께 열린 검은색 실행 창을 닫지 마세요.
4. 사용을 마치면 브라우저 탭을 닫고 검은색 실행 창도 닫습니다.

주문, 고객, 상품 데이터는 이 폴더의 `data` 폴더에 저장됩니다.
처음 실행할 때 기본 데이터가 자동으로 복사됩니다. 이후에는 EXE를
새 버전으로 교체해도 기존 `data` 폴더를 그대로 두면 데이터를 유지합니다.

백업 방법
---------

미르감이 종료된 상태에서 `data` 폴더 전체를 다른 드라이브나 USB에 복사하세요.

주의
----

이 프로그램은 내 컴퓨터에서만 실행되는 로컬 프로그램입니다. 인터넷에
공개하거나 여러 사람이 동시에 접속하는 용도로는 사용하지 마세요.
